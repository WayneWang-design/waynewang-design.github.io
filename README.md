# Wayne Wang — Interior Designer Portfolio

王東群個人作品集與簡歷網站。純靜態 HTML，無框架、無建置流程。

- 線上網址：https://wayne7111184-create.github.io/
- 首頁：`index.html`（螢幕為暗色版，列印會自動轉成米白 A4 三頁）
- 圖片：`uploads/`，檔名對應網頁上的順序

## 更新方式
1. 改 `index.html` 或換掉 `uploads/` 裡的圖
2. `git add . && git commit -m "更新內容" && git push`
3. 約一分鐘後線上就會更新
